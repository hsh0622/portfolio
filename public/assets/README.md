# Portfolio assets

아래 파일명을 그대로 사용하면 사이트의 플레이스홀더가 실제 이미지로 교체됩니다.

- `eolma-01.svg` ~ `eolma-05.svg` — 얼마 모바일 프레임 이미지 5개
- `clash-01.svg` ~ `clash-02.svg` — Clash 데스크탑 프레임 이미지 2개
- `devit-01.svg` ~ `devit-02.svg` — Devit 데스크탑 프레임 이미지 2개

파일명과 확장자는 `src/App.tsx`에 연결되어 있습니다. 다른 이름을 사용하려면 해당 배열의 경로를 함께 수정하면 됩니다.
